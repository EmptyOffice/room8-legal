## Analytics release checks

The disclosures describe the current default-on, device-specific Mixpanel integration and its US project region. Before publishing, confirm the actual Mixpanel retention setting and operational process for handling analytics deletion requests. Account deletion does not currently automatically delete historical Mixpanel data. Update the retention disclosures when a fixed period has been configured and verified.
